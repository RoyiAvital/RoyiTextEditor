# Queries

`<grammar>/highlights.scm` and most `<grammar>/tags.scm` files are generated by
`cargo xtask syntax-queries` from the queries of the grammar crates (a test
keeps them up to date). `upstream/` holds query files the Julia and MATLAB
crates do not export. Files starting with "written for RoyiTextEditor" are
this project's own.
